## 数据划分与预处理

训练2000—2021、验证2022、测试2023；按时间段划分后才生成历史与未来窗口，不允许训练窗口跨到2022/2023。读取小时文件名并核连续性，缺帧/原padding/finite哨兵明确拒绝或按预注册合法掩码处理；不补造物理场。小时输出与S7十分钟数据不直接混合。六变量TN/UN/VN为28层，WN/Z/DEN为29层，共171，aux每历史块6、scalar4，History输入354其余177；Z为位势高度非ZG。

所有新归一化只用训练split：逐变量/层means/std、气候态、log10(g/cm3)路径与指数反变换、标量及静态空间定义都版本化SHA。不能用验证/测试估计统计，也不能用2023重算后声称匹配官方权重。官方权重推理继续使用官方对应static。统计生成要流式float64累计，记录样本数/缺失掩码/年份/单位；与小样本独立求和核验。未来外部驱动的训练和推理可得性要一致声明，给定真实未来条件只能称HINDCAST。

## Direct基线、多步和密度损失的公平研究

先原Direct单步baseline：相同171变量与输入、官方架构、真实训练统计；原损失/采样/调度缺证据时不猜成“作者设定”，在独立训练配置中显式标注。用2022验证记录六变量分别SI、逐层DEN绝对/相对/log、固定上层组及极区、长时自回归、物理正性。多个seed（建议至少3，正式预算另定），参数量/训练updates/数据量/优化器/停止条件固定。

多步实验从相同训练初始化或冻结种子配对，K1与K2/K6逐一对照，所有未来物理状态反馈预测而非teacher forcing，除非显式另立训练策略。训练时是否截断梯度、各lead权重与总更新/算力预算必须在验证前说明；已知未来驱动仍按同协议。不同计算预算另报，不把更多训练算力改善归因结构。

损失候选先保留原baseline，再独立测试：(a) 标准化各层MSE的预注册均衡；(b) DEN log差/相对差；(c) 固定压力上层权重。相对损失分母下限只能用训练物理范围确定并记录，不能用2023调节；log预测与正性参数化/指数风险需训练验证，不能对负预测先clip再报指标。由训练/2022验证选择有限候选权重，保持其他变量的独立指标，不能简单加SI RMSE。训练层选择不得使用未来测试ZG挑有利层；固定物理意义与压力坐标，参考ZG分组仅评价附加信息。

本次Jan4/Mar24是已查看的探索性2023窗口，不能把它们当调参验证集再称独立泛化改善。2022验证内部可分开发/锁定子段，超参数数量有界，决定后冻结，再在未查看2023预注册窗口测试。若原模型已用2023选择参数，必须披露并另准备真正独立年份/观测数据。多种子统计以初始窗口为单位，格点不当独立重复。
