# TIE-GCM / Swarm坐标和高度登记审查

本次结论：模型原生坐标查询可用；ITRS/WGS84到原生ZG的严格适配仍不成立，外部接口必须拒绝。没有把椭球高、地心径向高度或有效重力半径直接充当ZG。

## 证据与可确认范围

2026-10-20重新访问[NCAR/HAO 2.0网格和高度说明](https://www.hao.ucar.edu/modeling/tgcm/tiegcm2.0/userguide/html/grid.html)。该文的地理网格为5°、36纬度中心（−87.5至87.5）、72经度中心（−180至175），东经为正，360°周期。它没有为整个动力网格明确指定WGS84椭球及高度零面。原始params.F声明glat/glon，getapex.F约132—145将ylatg弧度转成度并直接交给apex_mall；apex.F90约349—350把其入参定义为地理大地纬度/经度。这支持磁坐标映射入口把模型纬度当作geodetic使用，但不是整个球面动力学/下边界高度已在WGS84上严格登记的证明。不能因此另行把所有glat重解释为地心纬度，也不能直接把WGS84纬度和ZG配对作正式卫星查询。接口称其为“模型地理纬度”，不替调用者解决该歧义。

Zp=ln(P0/P)，P0=5e-5 Pa，是无量纲压力坐标。Z是模型常重力870 cm/s²下的位势高度；其下边界随潮汐/背景条件变化，不是常用地表标准重力位势高。ZG是经验变重力积分得到的模型几何高度；ZGMID是接口ZG到中点的登记。官方一般说明的中点密度不能代替本版本的具体实现：dt.F调用diags.F的mkdiag_DEN，源注释及实物共同确认DEN、ZG均为ilev，TN/风在lev。

## calczg完整计算链

原始third_party/TIEGCM2.0/src/addiag.F约161—203先将Z底层设为z_lbc，再按静力关系积分Z并调用calczg。lbc.F的tuvz_lbc先取背景资料或cons.F的zbound（136.291/sqrt(2)×1e5 cm），再加GSWM等下边界扰动。这个经验登记不能独立提供到现代参考椭球/大地水准面的严格转换。

addiag.F221—282，所有内部长度cm、加速度cm/s²：

- c2=cos(2×1.74533e−2×glat)。
- g0=980.616(1−0.0026373c2)。
- r0=2g0/(3.085462e−6+2.27e−9c2)，是匹配重力变化的有效半径，不是当地椭球表面地心半径。
- g(1)=g0[r0/(r0+(Z1+Z2)/2)]²。
- 平均粒子质量xmas=1/(O1/16+O2/32+HE/4+N2/28)/Avogadro常数。
- ZG底层=Z底层；随后ZG(k)=ZG(k−1)+kB×dz×TN(k−1)/(xmas(k−1)g(k−1))。
- 每层用g0[r0/(r0+(ZG(k)+Z(k+1))/2)]²更新重力。注意源码混用当前ZG和上一Z估计，不能改写成未经验证的解析椭球高度变换。
- 顶ZG=2×次顶ZG−再次顶ZG，是模型构造边界。
- diags.F约1327—1353：ZGMID取相邻ZG均值，最高中点另作构造。

官方把该经验重力描述为包括向心项的全球重力变化修正；这不等同于提供完整地球引力势/参考面。ZG零点继承下边界登记，源码没有在此引入WGS84椭球、大地水准面或一套可逆的ITRS坐标变换。因此不能从r0推导“地心距离−r0=ZG”。

## 外部候选近似与误差预算

候选A：WGS84纬度和椭球高作为模型纬度/ZG的近似。候选B：地心纬度、地心距离减固定球半径。两者均未获严格登记证据，本次不启用，也不生成对应的真实Swarm密度曲线。

误差项必须分别包括：椭球与假设球面的几何差、纬度定义差、下边界高度零点偏差、经验重力积分/顶边界构造差、垂直及水平离散误差、时间插值误差。前两项可由同一ITRS向量精确计算，不能由此约束未知的下边界登记项。WGS84赤道/极半径差约21 km只说明球面替代可产生km量级差异，不能把21 km当作ZG转换的已证明误差上界。未经官方澄清或独立登记数据，整体误差界仍未知。

若未来假设高度偏差δh，局部密度敏感性可用真实有效邻层的s=Δlnρ/ΔZG，估计ρ比=exp(sδh)；这只是条件敏感性，不是δh的置信区间。纬度偏差须另由水平梯度分析，不与高度偏差相抵消。特别注意极区经度退化：当前仅支持网格中心包围的−87.5至87.5°，更靠极点明确拒绝；未来极冠策略须有独立验证。

## 接口契约

原生查询：scalar UTC（Astropy Time或明确UTC字符串）、模型地理纬度deg、东经deg（任意360°等价值）、原生ZG米，并显式datum='TIEGCM_NATIVE_ZG'。输出密度kg/m³及有效标志/失败原因、数据源、时空邻点、权重、垂直层号和质量说明。DEN原g/cm³乘1000，ZG原cm乘0.01。只接受共同窗口10分钟完整序列，不外推、不补零。

外部查询复用DensityQuery的冻结时间/ITRS/WGS84入口，返回EXTERNAL_DATUM_UNVERIFIED；兼容阻力标量协议时抛出异常，避免误用为零阻力。后续需官方明确网格地理纬度与下边界高度登记，或经独立验证、具有可接受误差预算的适配方案，方可开启。
