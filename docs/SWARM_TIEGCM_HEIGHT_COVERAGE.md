# Swarm-A高度覆盖及有效率协议

源码defs5.0、params、addiag/calczg和现有NetCDF是定义依据。5°网格36纬×72经；lev/ilev是对数压力坐标的层中心/接口，不是km；配置ZIBOT=-7、ZITOP=7、步0.5。压力域固定，热力温度/成分/纬度重力变化使压力面几何高度随时空变化。

DEN在ilev、g/cm³乘1000转kg/m³；ZG同ilev、cm乘0.01转m；Z为位势高度，不可直接替代ZG。TN/UN/VN在lev，顶层padding约1e36，显式按变量dtype屏蔽，不能信任自动mask成功。DEN和ZG需同时间同水平列配对。

现有**2002默认**顶高448.964—513.086km；Swarm实际WGS84椭球高460.312—489.989km。存在超顶风险，但两者日期和垂直基准不同，这不是2023有效率。太阳活动增强可能抬高压力面，但还受温度、成分及地磁响应影响，禁止把预期当仿真输出。ZG参考椭球/模型地理纬度与WGS84的严格对应仍需源码/文档核实，是正式查询门禁。

未来每个历元先由完整ITRS位置得到共同基准地理位置/高度；必须有相邻两个有效模型时刻、四个水平角点（经度周期正确，极区单独验证），每个角点垂直单调、密度正有限，目标高度在全部8个时空列的共同高度范围。通过才允许逐列log密度插值及水平/时间插值；不跨缺值、不外推、不把超顶点裁到顶层。

新增src/atmosphere/coverage.py提供保守stencil_coverage门禁：输入已构造且已统一高度基准的8角列，返回valid布尔、总数/有效数/有效率以及时间、坏列、垂直越界计数（原因可重叠）。它不是完整坐标/插值接口，不能自行解决基准问题。合成测试覆盖正常、超顶、过期、单个角点过低、NaN等。实际2023有效率=N_valid/N_requested；未有2023场，因此**当前值N/A**。全轨道传播不得静默丢弃失败查询；主实验要求100%有效，否则停止或明确独立备用方案及适用区间。

覆盖不足的科学选择：选择完全覆盖的实验时段/低高度对象；或经单独批准研究官方支持的扩展顶界/新模型版本并重新做上边界与耦合验证；或建立有物理依据且独立验证的上层外推模块，作为另一个模型报告。经验模型补洞会使D成为混合方案，必须单独命名。不得改变ZITOP就宣称与官方2.0等价；扩大域会增加层数、时间/存储，并影响上边界条件。
