# FourCastDEN改进方向：证据、假设与验证路径（2026-10-22）

## 已证实的模型差别

官方README_inference_2023.md模型表与inference/inference.py::forecast确认：Direct直接预测下一步归一化状态，Flow预测增量再加当前归一化状态。两官方权重当前匹配同AFNONet结构、普通static、177输入/171输出/4条件、history=0。Direct和Flow参数值不同，不能把差异当成单一开关的训练消融；本次比的是两个作者已训练模型，未控制它们的训练过程和随机种子。

可验证的数学关系：对固定逐层mu/sigma，标准化状态差y(t+1)-y(t)=(x(t+1)-x(t))/sigma，mu抵消。因此Flow的物理增量只乘sigma。作者推理累加在归一化空间，未改变网络结构。Direct自回归会累积状态误差，Flow也会累积增量误差；若delta含系统偏差，多步累加可漂移。增量较小可能便于学习缓慢演变，但只是设计动机推断，不能从一组两小时结果证明其普遍优势。

公开源码包含L2配置和训练片段，但缺完整可执行训练入口、完整训练协议及训练验证数据，不能根据推理代码推断所有损失、调度、样本选择和训练公平性。论文入口https://doi.org/10.3390/rs18183134；本次出版社正文请求429，未声称本次重新阅读全文，模型行为以本地官方包为直接证据。此前论文资料与训练划分见FOURCASTDEN_PHASE2_RESEARCH_PLAN.md。

## 本次实际发现及局限

详见FOURCASTDEN_DIRECT_FLOW_COMPARISON.md。Flow第一小时TN/UN/VN/WN/Z平均层RMSE较低，第二小时TN/UN/VN/Z较低；DEN平均绝对RMSE约高2.9%，同时多数DEN层RMSE较低。这反映绝对量级/层权重的影响，不能据此认定某模型更适合所有高度。顶层绝对密度小而相对误差较大；需同时看逐层绝对、相对和log误差。两者六变量平均层误差从1h增到2h；Flow没有消除误差累积。没有出现负密度，但这不保证长时或强活动条件正性。

## 候选改进（仅设计，不训练/调参）

|优先级|候选|要检验的假设|必须补齐的条件|主要风险|
|---|---|---|---|---|
|1|log10 DEN或正性约束|高低密度层相对误差更均衡、保持正值|先复现官方log-DEN变体、static_log、独立同初值评价；已知NumPy/CUDA分支风险需隔离补丁审查|log与原空间均值不同，无法由本次短例选择最优；不得给旧权重直接换统计|
|1|逐层/变量损失权重|避免高密度底层主导目标，匹配未来关注高度|在训练/验证集预定义压力层权重与物理域，不能用2023测试选择权重|高度随时空变，不能简单把某ilev永远当450km；相对损失近零分母要预注册|
|2|多步自回归训练/阶段式展开|减少递归分布偏移|完整trainer、连续训练帧、验证时长、显存和吞吐小基准另授权|多步激活增长、暴露偏差，需与相同预算单步训练对照|
|2|条件编码改进|改善对F10.7/Kp及边界变化的响应|固定未来条件协议；明确hindcast与可预报条件两个任务|将未来实测条件优势误称模型自主预报能力|
|3|Direct+Flow混合/残差模型|兼顾绝对状态锚定与短时增量|训练/验证集确定组合方案，并保留单模型消融|禁止在本次2023窗口拟合混合权重后再宣称独立测试|
|3|AFNO频谱/patch/深度消融|提高精度与效率折衷|可复现训练和同数据同算力基线|架构变化需要新权重，不能加载不兼容官方权重后隐藏缺项|

每个方向先在严格留出的验证集决定超参数，再冻结到独立测试集。报告全变量/层/季节/活动分层、长时稳定性与正性、参数量、训练成本、在线预测成本；不能只优化DEN全层平均绝对RMSE。未来2023既用于公开测试，不应反复据其成绩调参。

## 与轨道目标的衔接

预测Z是位势高度，不能冒充ZG几何高度。AI场的小时分辨率与S7十分钟不同，未来必须独立核验时间插值、网格/变量/驱动映射及几何高度来源，不能悄用未来真实ZG辅助AI传播却称完整独立预测。WGS84/ZG正式门禁、真实Swarm气动、姿态和推力、完整共同受力及独立观测验证均未解决。当前改进只研究TIE-GCM模拟场预测，不能据此推断真实大气或卫星轨道精度。


## 五日期增补证据（2026-10-22）

MULTIDATE_COMPARISON表明第二小时Direct DEN绝对平均层RMSE在5/5窗较低，而Flow上层相对RMS/logRMS在5/5窗较低，支持优先检验log/分层目标的假设而非选择最终架构。Flow上层两步倍率五窗均更大，值得未来更长序列检验，不证明长期漂移。新增官方log-DEN仅静态检查、未forward。建议先变体复现与公平物理指标，再新增长时/强活动；训练/调参不能用这五个2023测试窗口。
