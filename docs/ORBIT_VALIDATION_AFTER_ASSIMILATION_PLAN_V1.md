## 2. 未来同一初态/受力的最小矩阵

拟以2022-03-24为与密度校正一致的目标日；需先另行取得同日期SP3和真实辅助，t0取**实际文件内合法原生P/V历元**，不假设2023文件的02秒相位必然适用于2022。积分t0至t0+6h，不能用未来SP3纠正状态。当前只列任务，不下载这些轨道/辅助、不传播。

三主组：NRLMSIS明确2.0（或另冻2.1）、原TIE、仅过去观测校正后的TIE；可另设NoDrag诊断，但也须计预算。所有组同P/V、地球与太阳常数/引力/星历/时间转换、真实m/姿态面积/Cd/推力、共同中性风假设、SRP/潮汐等启停、输出时刻与积分器，只换密度。不得同时改初态、风或Cd后把差异归于密度。

当前400kg/1m²/Cd2.2只能用于已授权的虚拟敏感性实验，**不能用于本方案的正式真实精度结果**。若真实参数未齐全，方案保持BLOCKED，不以演示参数补齐。

## 3. 初始化与密度约束的时间边界

- t0之前校正窗使用的最后密度观测严格早于t0，参数/核规则冻结；后续1/3/6h观测只评价，不继续校正。
- 不利用t0之后SP3插值改善初态、拟合Cd/面积/密度比例或高度偏移。任何未来校准另设更早独立窗口，并承认参数估计的不确定性。
- 单t0 SP3状态本身是后处理估计，不称为实时业务可用；另报历史TLE/SGP4初始化条件差异，不把SP3优质初态优势归于密度模型。
- 沿观测位置做密度验证与在预测轨迹位置查询密度是不同算子。SP3路径预检不能替代实际积分RHS逐次有效性检查。

## 4. 独立性、数值与误差报告

DNSAPOD由GPS/POD反演且与SP3关联，若用同窗密度拟合再对同窗SP3评价，存在循环/共享信息风险。需要：校正窗口与轨道验证窗口时间隔离；保留未用于选择模型的B/跨任务ACC密度验证；披露共同轨道/气动处理，不能只靠未来Swarm A SP3 residual证明独立大气改进。

轨道评价同时报3D/RAC位置与速度、全窗RMS/终点/最大值及分时效，不挑改善最好时刻。密度更接近某反演产品不保证轨道更准：Cd·A/m、风、其他受力/初态误差与密度误差可补偿，轨道动力学存在方向耦合。现有条件更新实验也有短期轨道差异反而增大的时段。

预登记数值策略：RK45 Tight复用rtol1e-12/位置atol1e-5m/速度atol1e-8m/s/max_step15s作为候选，独立DOP853参考另计预算；单轨≤0.02m、配对效应向量最大敏感性≤最大响应1%沿用，不能因效应小放宽。数值差与真实参考误差分别报告。密度时间分段/状态事件左右支正确处理，P/V必须连续。

模型失败/密度越界/未知推力不能补0、裁边或换源。若必须排除机动段，应按事前官方事件/质量规则对所有组同样处理，不能按残差删段。
