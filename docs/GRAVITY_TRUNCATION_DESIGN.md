# 地球引力截断敏感性预注册设计

## 目的与统一参数

8×8、12×12、20×20是在同一EGM2008势中分别保留n≤8、12、20及各阶全部m，不是更换地球物理模型或寻找最小SP3残差。全部采用源GM398600441500000m³/s²、R6378136.3m、fully_normalized/no CS、tide_free、C00=1、地心一阶为0。静态场不含2023潮汐/低阶世变。已有H1不能覆盖修改。

从已核实GFZ URL仅读65536字节前缀，关闭连接，不下载完整模型；检查前16384字节与原前缀逐字节SHA相同，检查所有n≤20/m≤n完整和重复/非有限值，保留HTTP及SHA清单。新源完整性未通过不得传播。官方源与模型定义沿用[GFZ](https://icgem.gfz-potsdam.de/tom_longtime)、[原gfc](https://icgem.gfz-potsdam.de/getmodel/gfc/c50128797a9cb62e936337c890e4425f03f0461d7329b09a8cc8561504465340/EGM2008.gfc)。

## 可回退实现

新gravity_truncation.ExtendedEarthGravity只扩展输入/系数初始化，继承原Cartesian势和梯度递推，原8×8文件不改。float64/complex128、n≤20的中间阶乘/多项式有限；不除极区水平半径。ITRS计算→原EarthFixedFrame/ERFA完整Q旋回GCRS，仅一个包含中心的力；不叠旧中心/J2，不新增虚拟力。不插值引力或轨道。

8阶系数和同位置力/势必须与原类逐元素相同，真实历史H1状态的各时刻也逐项验证；不重新传播H1。独立SHTOOLS Fortran使用同C/S，omega=0，near-pole比较；其精确极点求导不支持，生产极点单独有限性/邻近连续性检查。

## 预注册门禁（运行前）

每级100个随机点并赤道/近极、多高度：外部逐分量rtol2e−12、atol2e−12m/s²，向量相对差<2e−12；势中心差分h10km/1km/100m应二阶收敛，细步相对差<2e−8。8阶与旧类逐位相同，非法/缺项拒绝；通过全量测试后才执行。

共一次H3不超过600秒预检，H2/H3各一次21600秒主传播，H3 tight一次。初态/UTC/EOP/原RK45 base1e−10/30s、tight1e−12/15s及分量atol完全沿H1，输出60s共361点。阶段累计墙钟1800s/峰RSS2GiB，预检实测nfev/耗时用于保守预计，超预算停止不启动余下组。每组x模式launch_once，无自动重试，不走Restart。

数值门槛：H3 base/tight最大位置差<0.5m，关键H3−H2配对无法用H2 tight（不在本次授权）独立证明，须披露该限制。共同截断候选工程目标：H3−H2六小时终点<5m，另报告全段最大差和RMS；若全段最大差也<5m，可表述本窗口12→20差异小于该候选目标。5m仅为分辨历史52—65m密度差的目标，不是一般精密定轨标准，也不能证明20阶到无限阶收敛。未达标如实报告，不自动增阶或看SP3选阶。

## 输出与边界

H1只读，H2/H3无阻力；相同SP3后续仅评价，不拟合。PROVISIONAL / HINDCAST / NO_DRAG。日月引力、SRP、潮汐、相对论和推力仅用历史H1离线评估，不进入本次RHS。未来全部密度组须使用同一冻结引力及其他受力、气动和初态。
