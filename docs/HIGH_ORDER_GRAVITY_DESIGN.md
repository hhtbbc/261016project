# J3/J4受控带谐扩展设计

## 目的与物理含义

本次先改善不完整的引力基线，避免把非球形引力造成的残差误认成大气密度效果。J2是主要的二阶轴对称质量矩，反映赤道鼓起；J3为三阶南北反对称带谐，常以“梨形”帮助理解，但不是直接的地表形状；J4为四阶南北对称纬向质量分布修正。Jn是质量分布对外部引力势的展开系数，不是只由几何外形决定。

J3/J4系数约为10^-6，比J2约10^-3小数百倍；实际加速度还含阶次、纬度多项式和(R/r)^n，不能只比系数就推断轨道影响。在460—490km LEO应先计算实际量级及6h传播，不预设改善。各项会改变轨道周期、偏心率/近地点和短周期状态，米至百米累计位移有可能与此前密度敏感性同量级，具体以本次结果为准。

## 来源与一致性决策（编写生产代码前冻结）

1. [GFZ ICGEM模型目录](https://icgem.gfz-potsdam.de/tom_longtime)实际取得EGM2008 gfc地址，只读取文件前16384字节，包含文件头、C30/C40等低阶系数；不是完整模型下载。原字节及响应记录在data/raw/gravity_sources/EGM2008_HEAD_PARTIAL.txt和EGM2008_partial_manifest.json，SHA与字段转换在configs/higher_order_gravity.json。模型作者Pavlis等，论文DOI [10.1029/2011JB008916](https://doi.org/10.1029/2011JB008916)。
2. 文件头明确fully_normalized、tide_free，源μ=3.986004415e14m³/s²、R=6378136.3m。Cbar30=0.957161207093473e−6，Cbar40=0.539965866638991e−6；不是非归一化Jn。[IERS第6章§6.1](https://iers-conventions.obspm.fr/content/chapter6/icc6.pdf)也明确系数应和其缩放μ/R配套；其表6.2给出一致的舍入低阶值。
3. 为保证G0不变，保留原中心μ=3.986004418e14、R=6378136.6m和名义J2=1.0826359e−3，不改旧基础模块。新增项先Jn_src=−sqrt(2n+1)Cbar_n0，再Jn_project=Jn_src(μ_src/μ_project)(R_src/R_project)^n，使μR^nJn严格保持同一源带谐势项。不能直接复制归一化系数当Jn。
4. 这是**名义J2+重表达EGM2008 J3/J4**的明确定义受控势，不称完整EGM2008、完整IERS2023或统一已标定的现代地球重力场。原J2与EGM2008 C20有差异，原名义J2未建立完整潮汐系统登记；保留它是隔离新增项的实验选择。当前只比较新增n=3/4，不混入替换J2的效果。未来采用一套完整标准球谐场时，应所有密度组同时升级并核验潮汐/历元约定。
5. 静态EGM2008系数不代表2023年实时低阶系数；不加入世变、固体潮/海潮或高阶项。当前GCRS/UTC秒下的原型也尚未完整实现IERS坐标时缩放。重表达只解决参数幅值约定，不宣称已解决相对论时间尺度或全部物理一致性。

## 同一势及加速度

采用单位质量机械势U，a=−∇U：

U=−μ/r + Σ[n=2..4] μ Jn R^n r^(−n−1) Pn(s)，s=k·r/r。

k为单位对称轴。P2=(3s²−1)/2，P3=(5s³−3s)/2，P4=(35s⁴−30s²+3)/8，均为未归一化普通Legendre多项式。新增单项：

a_n=μ Jn R^n/r^(n+2) {[(n+1)Pn+s Pn′] r_hat − Pn′ k}。

中心项和J2仍由原two_body.py/j2.py计算；higher_order_gravity.py只组合明确开启的J3/J4，不重复J2。轴沿用EarthFigureAxis对地固Z在GCRS中的时变方向，冻结TT/UT1/xp/yp和60s轴插值。不固定GCRS Z，也不额外加入科氏/离心虚拟加速度。因为m=0轴对称，只需正确轴向，不依赖地球绕该轴的经度相位；用完整旋转矩阵变换位置/力应得到相同结果。

[GFZ STR09/02 §4.1](https://icgem.gfz-potsdam.de/docs/str-0902.pdf)给出球谐引力势及归一化定义；其正引力势W与这里U符号相反。独立测试用其展开的球坐标径向/纬向导数、scipy Legendre计算，再转Cartesian；生产实现用显式向量多项式。另做负梯度有限差分/复步长、几何奇偶性和旋转协变检查，不把两个相同函数互相比较冒充独立验证。

## 预注册门禁

测试/数值审计先于真实轨迹：解析与独立球坐标公式相对差<2e−12、绝对差<1e−18m/s²；复步长负梯度同门限；有限差分至少三档步长验证二阶收敛并在细步下误差<2e−7相对量级。固定轴保守合成轨道检查包含J2/J3/J4的完整能量及轴向角动量，不能要求角动量矢量不变。容差收紧应收敛，关闭J3/J4应逐元素恢复原J2 RHS/合成解。

只有独立门禁全部通过才允许G1/G2真实单次6h传播和G2 tight，共最多3次，不重跑G0。base/tight完全沿用旧配置；G2最大base/tight位置差<0.5m，新增相对G0的配对变化<max(0.005m,最大扰动1%)。原G0 tight已保存，直接复用；G1不单独tight，不泛称每项都已全面收敛。

新结果标记PROVISIONAL / HINDCAST / NO_DRAG；不使用合成气动参数，不能把旧密度矩阵与新引力组的差异归因于密度。无阻力的参考残差仅用于识别引力模型影响，SP3不是绝对真值，不拟合初态或系数。
