# 3分钟中文汇报：从理想更新走向可信轨道接口

李总，这一轮我们没有继续堆预测时长，而是解决预测结果接入卫星轨道之前的两个基础问题：卫星位置如何对应到大气网格，以及大气更新瞬间如何正确推进轨道。

上一轮的理想实验表明，使用未来TIE-GCM全状态在第六小时重新初始化，可以明显降低两个窗口的全球密度误差。例如Mar24 Direct第十二小时的高层相关层组误差，从约3.76%降到1.10%。但这只是理想全状态更新，不是实际卫星观测同化，也不能说明六小时就是最佳周期。

更新还有一个容易忽略的问题：七点之前预测的大气，与七点拿到新状态后的大气，并不是同一个值。如果把新七点状态直接接到六点后面做普通插值，就会提前使用未来修正。我们已经实现分支接口，分别保存七点左右极限。真实数据上192次查询全部与正确分支一致，其中4次遇到原有坏列会明确拒绝，没有补真值。

轨道积分也必须在七点停一下，保留完全相同的位置和速度，再使用新大气继续。我们用有解析解的短时阻力跳变测试验证了这一点：位置和速度没有跳变，只有加速度改变；收紧容差后，位置数值误差从约2.4毫米降到0.33微米。这是数值机制验证，不是实际卫星达到微米精度。

另一个关键发现是，Flow的一些高度失败并不是负密度，而是从界面密度和温度反推中点分子量时，交替的层间误差被放大。337个失败列中，334个的界面输入仍在范围内，中点反演却超界。独立矩阵和高精度重算支持这一解释，但还不能把它等同于网络违反完整物理守恒。不能简单裁剪后继续轨道计算。

外部坐标方面，官方资料仍没有提供模型ZG零面到WGS84的严格登记。旧实际轨迹的单因素敏感性显示，高度假设带来的密度差可以远大于纬度假设，因此不能随便把椭球高当成模型高度。正式接口继续关闭，只保留明确标注假设的虚拟演示。

Swarm能够提供沿轨密度和精密轨道，但不能直接提供全球171通道大气状态。现有本地观测也没有覆盖两个AI测试日期。下一步最有价值的是取得同时间观测、统一高度坐标并验证观测算子，同时检查高度反演的适用范围。条件具备后，再授权做大气更新前后的连续轨道对照；卫星位置速度不会在更新时被真值重置。本轮没有运行新的完整轨道、网络推理或训练。
