# S3完成后的S7决策与受控比较协议

本任务仅授权S3一支连续积分，S7未启动。S3单轨迹的稳定性和密度变化不能证明3天预热已经充分。Restart严格数值等价性仍失败，S7必须与S3一样从合法原始00:00初猜单次连续积分，不从S3检查点恢复。

## 决策门禁

先审计S3是否完成7210步、7个完整primary、293个secondary时间记录（其中共同窗口290帧）、真实驱动和数值筛查；冷启动首帧诊断量未计算是原生输出规则，明确标N/A，不冒充2023预测。其余全部记录要求有效。若共同窗口缺帧或数值异常，先报告失败，不自动运行S7。

Swarm高度与模型原生ZG需分别报告；即使原生顶高看起来高于460—490km，也不替代WGS84/模型纬度/高度零点转换、四水平角点×两时间邻点覆盖审查。若基准未闭合，可申请S7用于热层初态敏感性研究，但不能直接转入真实轨道阻力精度实验。

## 比较方法

1. 逐帧验证网格、年份/DOY/UT、lev/ilev、单位、掩码和驱动完全一致；DEN转kg/m³、ZG转m、风转m/s。不能直接把TN/风lev当成DEN/ZG的ilev。
2. 分原生压力面与双方共同有效几何高度域统计DEN的log比值/偏差/RMSE/P95/最大值、TN、UN/VN水平向量及主要组分差异，全球面积加权并分纬带、地方时及垂直层。报告覆盖率，不外推或静默删点。
3. 沿轨查询须先验证高度基准与时间/水平邻点，输出每点有效原因和单支/共同有效率；无效不填0，全48h轨道实验要求完整查询支持。
4. 沿用已预注册的工程候选标准：95%共同有效样本密度相对差<5%、TN<10K、水平风向量差<20m/s、主要非痕量组分相对差<5%，沿轨log密度RMSE<0.05；持续至少最后24h且无增长趋势。Restart冻结的float32/float64数值容差是另一类判据，不能混用或放宽。
5. 三个结论分开：S3/S7具体轨迹相近；对合法不同初猜足够不敏感；与真实大气一致。前者不推出后两者。后续同起日不同官方初态对照、独立观测和驱动/模型不确定度审查仍需新授权。

## 10分钟输出的限制

可离线在共同窗口用20分钟锚点插值到中间10分钟点，检查密度时变敏感性；它只衡量20分钟抽稀造成的误差，不能证明10分钟误差足够小。若时变剧烈或后续轨道误差预算要求更高，另申请短时1—5分钟参考输出和预算，禁止用平滑替代验证。模型输出已存在不等于可直接作为可信沿轨阻力输入。

本协议不包含S7执行授权，也不包含RK45阻力传播、Restart算法修复或FourCastDEN训练。
