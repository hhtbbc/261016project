# 约3分钟组会讲稿：大气理想更新的12小时轨道影响

这次我们把此前已经通过的一小时跨事件接口，推进为真正的十二小时条件轨道传播。使用一月四日凌晨一点到下午一点已有的Direct大气预测，七点进行一次理想大气更新。四组分别无阻力、原预测密度、更新密度和TIE-GCM参考密度；卫星初态、力模型和合成气动参数完全一致。

实验不是重新训练网络，也没有使用未来精密轨道纠正卫星。初态来自事后精密轨道插值，随后十二小时完全积分。七点只改变大气场，位置速度严格连续。相同卫星位置上的密度跳变约7.76%，对应阻力加速度变化约1.02e-08米每二次方秒。

阻力变化先累积成速度差，再在轨道动力学耦合下形成位置差。十二小时末更新与原预测轨道相差4.698米。相对于TIE-GCM条件参考轨道，原预测终点差9.178米，更新后为4.482米。全窗RMS分别是3.494与2.115米。我们还检查了中间时刻：更新后360个一分钟采样中有23个点更新组反而更远，因此要同时看全过程和终点，不能只挑有利结果。

为了判断差异是不是积分器造成的，我们按事前冻结的Base和Tight设置各做四组，共八条轨迹，并直接比较六种配对差向量。数值结论是：冻结数值门槛未全部通过；不放宽阈值、不重跑，以下数值仅为尚未完成数值资格确认的条件计算。未通过的结果会保留并明确标注，不为了获得通过而修改阈值。

所有密度查询均通过有效域检查；07点未跨分支插值，没有补零或换模型。但坐标映射仍采用披露的A假设，质量、面积和Cd仍是演示参数，TIE-GCM参考轨道也是模拟结果。因而这次测量的是大气输入变化对条件轨道的影响，不是实际Swarm轨道预测精度。

下一步应优先解决外部高度登记和真实气动、姿态与推力条件。如果需要进一步数值验证或多日期实验，也应先冻结预算和准入标准，不自动扩展计算。这样才能把工程链路逐步推进成可验证的真实卫星应用。
