## 3. 无扰动与比较门槛

先用新参考的共同输出与旧未插桩轨迹同UTC比较，记录位级/原冻结数值门槛。该比较受既有C/S舍入背景限制：通过外场比较不等于所有内部量位级不变。若探针导致明显超差，停止归因并检查编译、求和次序和缓冲复用。

现存标准变量保持旧SI容差/掩码规则。对新增内部数组优先逐位比较并报告绝对/相对差；没有预注册量纲阈值的量不擅自发PASS。需结合离散尺度及控制重复背景预先确定资格标准，不能按看到的恢复误差调整阈值。进程本地数组要按真实分区对应，跨rank全局汇总不得改变物理归约路径。

## 4. 仅在证据成立时采用的最小修复

1. 若P1标准状态已不一致：先修正独立适配层的记录选择、维度/时间槽或halo恢复；不能先新增四磁数组掩盖读入错误。
2. 若P1一致、P2磁势往返有超差：候选是独立版本的原磁格状态sidecar，绑定完整primary记录SHA/UTC/网格/编译身份。不能将地理POTEN简单reshape，不能补零。
3. 若P2磁势相同而P3电场不同：核查pthreed与首步pefield的差分/边界/时间层，优先准确恢复必要跨步场，或证明相同算法确定性重算。**不能全局把istep伪造为11**，这会跳过GPI/GSWM/ESMF必要初始化。
4. 若磁场相同仍分叉：继续P4的历史层、化学、过滤和几何审查，不追加未经证明的缓存字段。

任何修复都只在独立源码副本；原方程、边界、A14/B14、small、科学验收标准不变。修复后必须重新通过连续/恢复资格，随后才有资格开展正式插桩无扰动和预算闭合。现阶段未产生可声称“已修好”的补丁。
