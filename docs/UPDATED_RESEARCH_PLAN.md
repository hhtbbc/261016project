## 总目标与三阶段
在可验证精度前提下，研究大气密度改进对低轨卫星轨道预测的影响及计算效率。
1. 当前第一阶段：真实LEO SP3参考 + 历史TLE/SGP4基线 + 经验大气/RK45 + TIE-GCM 2.0/RK45。先解决时间、坐标、初始状态、力模型和大气接口，再比较误差。
2. 第二阶段：在明确、相同的数据和评价协议下复现FourCastDEN，再研究架构与训练方法；早前单小时测试仅作为已有工程基础，不视作已完成这一阶段。
3. 第三阶段：用改进AI替代高成本大气数值模拟；检验轨道误差和总计算成本，不能只比较网络前向和物理模型全部启动成本。

## 当前实验主线
Swarm-A → 同期SP3-d/历史TLE → 统一时刻/框架 → A:SGP4；B:NRLMSIS+RK45；C:TIE-GCM+RK45 → SP3位置/速度与RAC误差 → 精度/效率/风险报告。
B/C使用完全相同初始r/v、质量/面积/Cd、共同风场假设、其他受力、RK45容差/步长/输出时刻；只替换密度提供器。最初共同风设为零，仅包含地球共转，不能只给C加入TIE-GCM风再把差异解释为密度贡献。
RK45只是数值积分方法，不能预设其准确于SGP4。中心引力+J2+阻力是基础原型，距高精度定轨完整受力模型还有差距。
