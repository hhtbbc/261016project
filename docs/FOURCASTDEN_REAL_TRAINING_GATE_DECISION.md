# 独立真实Direct训练前的门禁决策

版本training_window_mar23_v2。当前科研身份是基于FourCastDEN公开架构的独立数据/训练工程，不是作者原始训练集或完整训练协议复现。

## 门禁定义

- 两年驱动/GPI、独立连续运行、候选提取和只读接口均须有实际审计；2021训练与2022验证按年份/UTC完全分离。2023始终独立测试，禁止训练或调参。
- 数据接口工程PASS不等于科学数据READY。两年都只有2002完整初猜出发的单次运行，7天预热没有同驱动合法初场/更长预热配对证据，必须保留SPINUP_SUFFICIENCY_UNVERIFIED。正常时间变化、两年分布差异都不是初始化误差的直接测量。
- 只有73/49帧，小时样本还存在时间相关性，不能证明全年、不同季节或太阳活动的泛化。

## 优先工作：预热敏感性

建议先进行预热敏感性研究，再决定科学训练数据接受范围；本次只设计。优先同起始历元、同驱动、同模型配置，使用另一合法完整同网格官方初场，与现有轨迹在相同目标时刻比较。不能把不同分辨率初场直接拿来用，不能伪造_NM或重标时间。

若只能考虑更长预热，可预注册14天候选，从03-09起分别连续至2021-03-26和2022-03-25，比较同目标窗口的DEN、TN、风、组分和ZG结构。需要先扩展GPI合法域和中心81日原始Fobs支持：候选2021 raw03-07至03-28/Fobs01-26至05-07，2022 raw03-07至03-27/Fobs01-26至05-06；须实际代码核算及重新审计，不能直接越过现有03-16合法起日。

更早连续积分改变了目标窗口前的大气状态和历史过程，不是任意改日期的单点对照。应保持共同窗口的真实驱动及所有其他配置相同，沿用DENSITY_COMPARISON_DESIGN、NEXT_SPINUP_EXPERIMENT与窗口v2的预注册多变量门槛；不得按本次结果事后放宽。不能只看全球均值或仅DEN单项。

17/16天新积分的时间、磁盘、安全系数须依据实测重新预算，可能超过当前单次3600秒门槛，需另授权，不能自动追加。没有合法配对时，科学质量状态继续UNVERIFIED，不删除不利时刻求PASS。

## 真正训练前还须冻结

1. 预热/物理质量适用性，以及独立生成数据相对作者版本、初场、驱动、潮汐/下边界、采样的分布差异。
2. 训练统计仅从质量通过的2021训练数据生成，明确是否逐通道/层、单位、顶部padding剔除、掩码、dtype；保存统计方法及SHA，再固定应用2022。不得混合2022或2023生成统计。现有官方static仅用于已完成的只读兼容性检查，不自动用于独立从零训练。
3. Direct单步基线的模型结构、随机种子、损失定义、纬度权重、优化器、学习率/调度、梯度裁剪/AMP、训练步数、采样顺序与checkpoint恢复协议。作者缺失细节须标独立实验选择，不把合成SGD设置直接升级为科学协议。
4. 独立2022验证的评价单位、逐层绝对/相对/log DEN、400—500km相关原生层与覆盖率、温度/风/Z、持续性和多步评价；不把验证数据用于参数梯度更新。本次未用验证误差选择任何权重或超参数。
5. 小样本过拟合风险、训练/验证曲线和复现预算；后续单步与K=2多步等单因素对照同时记录更新数及额外forward/backward成本。改进研究须独立验证，不能用2023测试反复优化。

因此，候选数据完整后可以另行设计明确标注假设的小样本工程训练，但不能直接宣布正式科学训练数据READY，也不自动启动训练。本次无正式统计拟合、网络forward/backward或optimizer.step。
