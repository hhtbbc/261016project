# 技术路线（设计，尚未实现）
TIE-GCM物理场 → FourCastDEN/AFNO小时预测 → 反归一化与物理单位核对 → 结合时间/地理坐标/压力层高度查询密度 → 单星受力方程 → RK4/RK45 → 轨道指标与可视化。

- atmosphere：数据读取、模型适配、时间/空间/高度插值、可替换密度接口。
- orbit：中心引力、J2、大气阻力，后续日月引力；状态为位置与速度。
- integration：在统一时间、单位、坐标约定下连接大气与轨道。

接口实现前必须确定密度单位、压力层到高度映射、ECI/ECEF、风场与自转速度。当前不假设原始DEN单位，不把模型压力层当作固定几何高度。实验区分数值参考验证与观测验证。
