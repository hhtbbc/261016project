## 2. 不重启的输出与检查点策略

两分支各只启动一个进程组，从各自起点到共同终点自由连续推进；START/STOP/HIST序列仅改变写出调度，沿用已验证相接序列机制，不意味着停止/重新初始化。未来运行器须先计算numfiles.F输出数并提供足够且唯一的OUTPUT/SECOUT文件名；所有配置/二进制/驱动哈希归档，不覆盖现有run-tag。

primary：初始及每日00:00、最后03-23 00:10，原生完整34字段/双层/下边界，每文件1帧MXHIST_PRIM1；S3共7帧，S7共11帧。可用相接“起日→DOY82 00:00，每24h”和“82 00:00→82 00:10，每10min”配置实现，接触点不重复。它们用于故障审计/状态演化，**不宣称可可靠恢复全部电动力内部状态**；磁坐标内部数组的精确保存需后续独立修复。未来必要时另设计只读原生内部状态快照，但不混入本次未改可执行的受控对照。

secondary：预热期每天00:00稀疏样本（不重复共同窗口起点）；共同窗口10分钟间隔、290帧。按相接序列“起日→DOY80 00:00，每24h”和“DOY80 00:00→82 00:10，每10min”，得到S3总293帧、S7总297帧。保留既有26字段以维持诊断可比性：DEN/ZG、TN/UN/VN、O1/O2/N2/HE等，并记录太阳/地磁标量。按24帧/卷MXHIST_SECH24，预留13个独立次历史文件名/分支；实际numfiles.F必须在生成阶段复核。每卷约184MiB，避免单资源>5GB。

10分钟输出为成本与插值误差的候选折中，尚未证明足够支持轨道精度。先用离线10/20分钟抽稀的内部一致性测试估计时间插值敏感性；这不能证明10分钟本身的误差，必要时另授权局部1—5分钟输出参考，重新计算预算。不把10分钟插值数据称为60秒原生输出。跨午夜读取GPI、日志每个可见时刻与独立公式核对，关键日期午夜/强驱动变化列专题。

## 4. 运行与停止门禁（需另授权实现和执行）

先只申请S3单支；核验启动/每日推进/终点、输出体积/吞吐、真实驱动与物理筛查后，再决定S7。任一支失败不自动重试、不从有缺陷Restart续算；保留部分结果，重新申请最小修复或整支重跑的预算。连续方案因此具有失败损失较大的风险，但当前估算仅十几到二十几分钟。

启动前核验SHA、源只读、GPI每日边界、5°/MPI4/STEP60、输出数量/位置、完整00:00源/配置、禁止固定覆盖、剩余空间；独占launch_once。进程树每0.1秒采样资源，生成量每秒累计整个run目录和日志；墙钟、RSS16GiB、4GiB产物或余盘20GiB任一越界先TERM进程组、宽限后KILL，保留日志，不启动下一支。每卷<=256MiB作为额外文件预算目标，单进程文件限制不得误挡正常滚卷。

日志发现NaN/Inf/错误、MPI异常、未在预计周期写进度、驱动越界/固定覆盖即停。每分钟日志心跳，120秒无进度为停滞候选（需辨别IO），每个完成NetCDF文件/记录检查非有限数、DEN>0、ZG逐列增、掩码/组分；在线读应使用已完成卷或确认写完/flush的记录，不并发读取尚未完成的结构。TN100—5000K、|UN/VN|<2000m/s只作预注册宽松故障筛查；组分在容许浮点误差内0—1、O1+O2+N2+HE近1。日志未输出的物理量无法每60秒实时检查，必须明确检测延迟，不能宣称所有步已排除瞬态。

输出完整、时间网格完全一致、MPI正常结束、驱动核验和基础场通过后才进入收敛分析；不因程序退出0就直接用于轨道。

## 5. 收敛检查：方法、指标与预注册候选门槛

共同时间轴固定2023-03-21 00:00至03-23 00:10（290帧）。逐帧核对纬经度/lev/ilev/单位/网格、时间系统和掩码；DEN g/cm³乘1000、ZG cm乘0.01、UN/VN cm/s乘0.01。TN/风的lev顶padding不能当有效场；DEN/ZG是ilev，不将lev与ilev按同索引直接配对。N2为输出成分，不冒称primary另存的独立预报字段。

比较域一：相同原生压力面。DEN报告log比值Δ=ln(rho_S3/rho_S7)、相对差(rho_S3−rho_S7)/rho_S7、偏差/RMSE/中位/P95/最大值；TN单位K、风单位m/s、组分质量混合比报告绝对差与相对差（低于1e-8的痕量不使用相对门槛，仍报告绝对差/覆盖率）。全球面积加权采用真实纬度带面积；逐层统计，不能将不同密度量级的所有垂直层混成一个RMSE。报告全球、纬带、极区、地方时分箱和异常最大点，不只比较全球平均。

比较域二：共同几何高度200/300/400/450/475/500km（候选，不保证各列覆盖）。先核实ZG为几何高度及零点/参考椭球与查询高度一致；每列只在合法相邻ZG之间插值log DEN，温度/风先将lev场与对应物理高度正确配对。仅取两支共同有效域，报告每层有效比例、单支越界原因；不得外推或通过删除未覆盖区粉饰指标。高于模型顶界的层标作不可评估。

Swarm沿轨：复用已验证SP3/GPS→UTC和ITRS/GCRS工具，在真实评价时刻用相同位置/时间分别查询两支；经度周期处理、极区、水平邻列有效性及时间两端都检查。几何高度必须先闭合ZG与WGS84/地心半径关系，不能直接混用。每次查询保存有效标志和原因（时间、水平、垂直、缺失）。统计两支各自及共同有效率、最小顶界裕量、连续失效区间、沿轨log密度偏差/RMSE/P95和分圈趋势；无效点不设0，主评价窗口要求每个查询合法（目标100%），未达到则不直接开展全48h阻力精度实验。已有03-19顶高545—677km不能替代目标日期实际覆盖。

候选工程门槛沿用旧初始化方案，而非官方科学准确度保证：每个可比较层/纬带的共同有效样本至少95%满足密度相对差<5%、TN差<10K、风水平向量差<20m/s、主要非痕量成分相对差<5%；沿轨log密度RMSE<0.05。报告阈值分母、加权方式、P95和绝对差，不事后放宽。最后至少24h稳定满足且逐6h统计的差异没有显著增长（预注册拟合log密度RMSE随时间斜率及不确定度，同时展示时间序列）；若强驱动期不满足，保留失败，不以人为平滑掩盖。

分析TN/风/DEN/成分的共同演化及3/7天差异是否衰减，区分驱动诱发的真实变化与初态差异。仅3/7两支相近只能说明这两个具体历史路径在共同窗口相近。要支持初态无关性，后续还需同一起日、不同合法官方初场（如smin/smax，先检查真实文件）的独立对照，以及必要的更长积分，均另授权；默认春分低太阳场不是实际2023观测。要论证真实大气准确性还需独立密度/温度观测、误差与驱动不确定度评估；Swarm DNSAPOD与POD/SP3共享信息，不能作完全独立真值。不能从收敛相似直接推导轨道精度改善。
