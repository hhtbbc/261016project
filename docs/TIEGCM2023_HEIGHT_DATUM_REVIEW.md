# S3/S7比较中的高度与坐标审查

## 已核实

[NCAR/HAO官方2.0网格与高度说明](https://www.hao.ucar.edu/modeling/tgcm/tiegcm2.0/userguide/html/grid.html#altitude-coordinates-in-the-ncar-tie-gcm-and-time-gcm)明确区分压力坐标、Z与ZG，并建议固定高度登记使用ZG。Z按常重力定义；ZG通过calczg中的变化重力积分计算。中点场可用ZGMID登记。

本地addiag.F221—282中，g0依纬度而变，r0是有效半径，底层ZG取底层Z，向上积分后构造顶界。diags.F1327—1353中的ZGMID用相邻接口ZG的均值，最高中点为构造值。本任务不修改顶界或几何参数。

官方概述中“中性密度在中点”的一般描述不能替代具体变量定义：dt.F266调用mkdiag_DEN，diags.F417—439注明rho在接口，实际文件DEN和ZG均为ilev；TN/风/主要组分是lev。故本次DEN可与ZG直接成对插值，而TN/风只先在原生lev比较，不能把同索引ZG当其中点高度。

## 本次允许的比较

S3/S7使用同一模型、参数、网格及高度计算定义。在两组各自单调有效的ZG列内，对相同原生ZG目标200/300/400/450/475/500km作log密度插值，严格报告双方共同有效域；这是同一模型高度定义下的敏感性比较，不把这些高度标作WGS84椭球高。NaN/填充值/超出任一列范围均拒绝，不作外推。

## 仍未闭合的外部参考关系

- 文档没有明确给出ZG零点对应WGS84、某一大地水准面或其他精确参考面的转换。
- calczg的经验重力/有效半径及下边界登记不足以独立推导严格的椭球高转换；不能把r0解释成每点WGS84地表半径。
- apex模块某些接口接受geodetic输入，不等于已证明整个热层网格纬度、ZG零点与Swarm的ITRS/WGS84坐标完全一致。
- 地心距离减6371km只能作为另一种标明定义的径向高度，不是ZG转换公式。

因此，本次精确沿Swarm密度查询有效率保持N/A。原生全球顶高大于卫星椭球高，只提供数量级风险信息，不替代8个时空邻列、经度周期、极区及真实参考面检查。未进行密度补零、越界外推或轨道传播。

后续应核查模型下边界高度资料的登记约定和纬度定义，必要时向官方确认；建立具有明确近似误差预算的高度适配，再用合成坐标测试、真实轨迹邻点覆盖测试验证。未经证据不能为了进入集成宣称问题已经解决。
