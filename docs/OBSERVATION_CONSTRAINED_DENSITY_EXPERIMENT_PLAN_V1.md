## 3. 受限log残差的工程候选（不是已验证最优参数）

历史合法点`e_i=ln(rho_obs_i)-ln(rho_TIE_i)`。采用局部加权常数而非高维全局修正；下列数值为事前工程选择，需在下一轮启动前最终冻结，不从B或未来误差调参：

- 历史最多3h，时间年龄指数权重tau_age=1h；全部t_i<cutoff。
- 水平球面距离紧支撑R=1500km，使用明确6371km球半径的工程距离，只用于核权重，不作为TIE高度转换。
- 观测/查询外部高度差≤25km，地方时周期差≤2h；地方时取UTC小时+经度/15的平均太阳时近似，明确不冒充太阳视时。
- 至少6个质量/模型查询合法历史点且权重和正；这不是6个独立观测的统计保证，另按轨道段/时间块记录代表性。
- `e_bar=sum(K_i e_i)/sum(K_i)`，未来作用按`exp(-(t-cutoff)/3h)`衰减；不使用t>=cutoff的真实密度更新e_bar。
- 若无支撑、离高度带太远、参数无效或|e_est|>ln2，**不应用修正**，保留原合法背景并返回CORRECTION_NOT_APPLIED及原因；不悄悄裁剪e或制造全球修正。
- `rho_corrected=rho_TIE*exp(e_est)`，只作用于输出密度，不修改TN/风/组分/压力/ZG/PRIMARY，不称为已改进初始状态或守恒三维分析场。

校正器无支撑时回到原背景是事前定义的方法边界，不是密度查询失效的补洞。若原背景密度无效，该点仍拒绝并记录，不能借“校正未应用”隐藏。

方案C加入过去C时，先各星内部归一核权重，再按A/C各1/2混合，不让近邻重复记录自动变成两倍独立信息；该权重不消除共同POD系统误差。未来若建R/协方差，需用开发时段估计相关性/合理稀疏化，不将30秒点独立高置信计权。

## 4. 公平评价及不能跨越的推论

所有方案同UTC/位置/真实高度、同质量过滤、相同共同有效样本ID，另外报各自模型查询/校正支撑覆盖和失败原因；全观测窗口与各纬度/高度区、事前3h或轨道块均报告。

普通MAE/RMSE/Bias/relative RMS/有符号relative Bias/Pearson，单位kg/m³、正观测不事后调分母；log误差另列。分开报告拟合分析、cutoff诊断、未来1/3/6h；不能用最后一个时效择优挑模型。

## 6. DART后续定位

DART用于进一步把观测约束传播到TN/风/组分/电离层状态，具有纯输出校正不具备的内部耦合价值；但必须先通过：

1. 正确单位/层/高度与He观测算子独立核验；
2. 合法完整背景成员与同UTC secondary，非伪造状态；
3. 零增量状态文件round-trip、短连续/分段恢复资格；
4. 观测误差/时间相关性、集合局地化/膨胀及成员物理范围；
5. 分析状态可继续积分，未来观测严格关闭。
