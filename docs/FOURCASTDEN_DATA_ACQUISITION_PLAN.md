1. 先split清单再构造pair，2000—2021 train、2022 val、2023 test-only，所有输入/label/历史帧不得跨split/年份。新统计只训练集计算，验证/测试不得参与。
2. 用作者dataset.get_data已验证预处理→OfficialFrameSource→EpochPairs，独立raw通道/均值标准差核验；当前state+目标aux/scalar构输入，未来state只label。归一化/反变换与单位分别测试。
3. 执行batch1少量train_step/validation_step，梯度/loss/参数更新/无更新验证、有限性/资源完整记录；数据epoch按manifest抽查，无2023。真实训练标签需独立配置，不沿用合成授权。
4. checkpoint包括model/optimizer/scheduler/step/RNG/数据及统计SHA；中断恢复后与连续CPU/可行GPU短例比较，保留所有失败，不用未来真值重置预测。
5. 训练loss/验证loss分别绘图；验证单步六变量SI/逐层DEN绝对及相对/log/极区/上层/持续性，另预注册多步1—6h真实验证目标；不把训练片段overfit当泛化。

7. 记录GPU构建/forward/backward/step/I/O/保存时间和allocated/reserved/进程显存、RAM/存储。新AdamW、多步/大batch须实测预算，不用本次SGD推算完整训练天数。
