# V60 小型 Direct CPU 训练和跨年工程验证

**V60_TINY_DIRECT_CPU_ENGINEERING_COMPLETE_VERIFIED**。一次 CPU 训练成功。模型在 2022 历史工程验证中三个时效的全球绝对 MAE/RMSE 都低于三基线，全球 log RMSE 却全部更高。现阶段保留 Persistence 作必备对照，不将 Direct 作为全层替代。

## 权限、配置及隔离

起始 HEAD、远端和 V59 发布身份为 98149a3dcf361c1c9d16cab16ba472a9351d536f。V58/V59 收据、两组 ELF/GPI/启动身份与 32 卷次历史 SHA 复核通过。使用原封存表的 2021、2022 秋季各四个 06Z/18Z 截点和各 12 个端点。V60 独立授权重用 V59 已转换的 kg/m³ 历史和标签切片，逐件核对 SHA、原生网格和 UTC；本轮新读取 NetCDF 密度记录数为 0。训练侧只打开 2021 数组，2022 数组中的 12 个目标场仅在预测锁之后访问。V37、Swarm、外部 ZG 门禁保持。未运行新的积分、正式科学评分、AFNONet、GPU、DART 或轨道任务。

预先固定种子 42、Adam 学习率 0.001、batch 为一个截点、80 步和 UTC 顺序。输入和输出分别为 [4,3,29,36,72]，三输入为截点前 −3/−2/−1 小时，三输出为 +1/+3/+6 小时。29 个压力接口共享卷积参数。3×3 卷积通道 3→8→8→3，两次 ReLU，共 1,027 参数，无层位辅助通道。零初始化最后一层，初始 log 预测精确等于 Persistence。采用周期经度、反射纬度，边界行为由合成矩阵验证。纬度反射是数值处理，未包含完整极点物理。

log 输入按层归一化，均值和总体标准差只从 2021 历史输入估计，排除训练目标及 2022 数组。输出残差加最近场的 log DEN。损失为三时效等权的原生纬度加权 log-MAE，每次更新一个截点，四截点循环；无裁剪或验证侧调参。DEN 代理标签和输出均位于固定压力接口，ZG 仍不具有跨源外部高度证据。

锁定 checkpoint 和归一化后，把已训练参数导出给独立 C 推理程序。沿用 V57 chroot、UID/GID 65534、no_new_privs、seccomp 白名单；每次只呈现该截点 3 个历史场和冻结参数包。12 项真实路径访问探针通过，含外部目标档案与原始模型文件路径。改写沙箱外合成哨兵，预测字节逐一相同。24 个预测用 memfd 内核封印并锁定磁盘预测 SHA 后，由可信评价器读取标签。评价前后归档 SHA 一致。复核的 C 与 Torch 输出最大相对差 2.05e−6，使用不同的浮点计算精度。396 行 Direct 指标独立复算，最大相对差 7.90e−15；1,188 行基线数据与 V59 的准确年份子集匹配。

## 2022 同样本验证

各方法自身有效口径，按时效排列。绝对误差用 kg/m³，log RMSE 无量纲。完整结果另含四方法共同掩码、Bias、相对 RMSE、面积加权 P95、各原生层位和区域。

| 方法 | +1/+3/+6h MAE（×10⁻⁹ kg/m³） | +1/+3/+6h RMSE（×10⁻⁹ kg/m³） | +1/+3/+6h log RMSE |
|---|---|---|---|
| Persistence | 2.064 / 3.742 / 5.046 | 7.138 / 13.064 / 18.209 | .04115 / .07450 / .10789 |
| 原值线性 | 1.338 / 4.014 / 8.772 | 4.474 / 13.490 / 29.744 | .02993 / .07955 / .16733 |
| 对数线性 | 1.331 / 3.988 / 8.713 | 4.459 / 13.441 / 29.714 | .02993 / .07910 / .16159 |
| TinyDirectCNN | .8955 / 2.201 / 3.531 | 2.828 / 7.049 / 11.027 | .07290 / .20872 / .34095 |

相对 Persistence，Direct 的 MAE 降 56.6%、41.2%、30.0%，RMSE 降 60.4%、46.0%、39.4%；log RMSE 增 77.1%、180.2%、216.0%。相对各时效最佳基线，Direct 的绝对 RMSE 仍降 36.6%、46.0%、39.4%。四方法共同有效口径结论一致。Direct、Persistence、LogLinear 均 100% 覆盖；2022 原值线性 +6h 覆盖 99.99634%，有 11 个非正格点。Direct 没有非正或非有限值。

全球绝对误差下降掩盖了层间退化。相对 Persistence，+1/+3/+6 h 分别有 21/22/23 个层的绝对和对数 RMSE 增加。最差的相对恶化在原生索引 10，+6 h 层 RMSE 约为 Persistence 的 9.74 倍。极区 log RMSE 从 Persistence 的 .02749/.04811/.06761 增至 .07237/.20908/.34452。+6 h 随时效放大较明显，即使密度保持为正，仍不能视为物理误差可接受。

2021 训练侧 Direct 的 MAE 为 .8594/2.091/3.304（×10⁻⁹ kg/m³），RMSE 为 2.805/6.986/10.894（同单位），log RMSE 为 .01558/.03377/.04565。2022 全球绝对 RMSE 与 2021 接近，但 log RMSE 约为训练侧 4.68、6.18、7.47 倍，表明相对误差的跨年退化。每侧只有四个高度相关的截点；这个差距支持过拟合或分布差异的风险，不能在当前设计下识别成因。

## V61 决策

这个实验提供了模型代理任务中绝对误差下降的工程证据，同时发现低密度层和极区的相对误差恶化。暂不增加网络复杂度，保留零初始化 Persistence 残差结构作为候选，先扩大合法数据。V61 最有价值的工作是预登记按独立地磁事件分块的扩展样本，并锁定层位和极区 log RMSE 的安全比较口径。最低需要一个未参与模型选择的外部块；若研究跨活动水平，至少预先定义静稳/扰动两档，每档收集多个独立事件，再根据事件方差估计所需规模。当前没有足够独立事件给出统计功效。2022 数据本轮已用于工程判断，不能重新称为独立测试。扩展日期和模型标签、下一次训练、额外积分、Swarm 解封均需分别授权。正式 V37 科研评分仍未授权。
