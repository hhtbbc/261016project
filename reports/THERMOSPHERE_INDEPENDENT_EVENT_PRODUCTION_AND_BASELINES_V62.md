## 已执行的三种无训练基线

先冻结配方、生成并锁定 24 份预测 SHA，再打开已授权的秋季目标。每格 z=ln(DEN)，A 在 −3/−2/−1h 拟合直线，截距以 −2h 为中心，预测 mean(z)+(h+2)(z[-1]−z[-3])/2。B 使用相同斜率但锚定最新帧，并积分时间常数 3h 的指数衰减，时间常数在评分前固定为一个 Kp 时间桶。D 令太阳地方时相位 λ+15°×UTC 小时不变，从更早的帧采样东经增加 15°×(h+1) 的位置，360° 周期包裹；非整数移位对 log DEN 周期线性插值。此实验 5° 网格与整点实际都是整数移位，合成测试检验了半格接缝、方向及波形；D 是日周期结构代理，未模拟物理输运。C 的 24 个所需的 t+h−24h 时刻均在归档时间轴存在，尚未授权作为历史输入，状态 NOT_EXECUTED。

2022 旧工程验证，四个旧方法和三种新方法的共同有效格点，按 +1/+3/+6h 排列：

| 方法 | 全球 RMSE（×10⁻⁹ kg/m³） | 全球 log RMSE |
|---|---|---|
| Persistence | 7.138 / 13.064 / 18.209 | .04115 / .07450 / .10789 |
| 两帧原值线性 | 4.474 / 13.490 / 29.744 | .02993 / .07955 / .16733 |
| 两帧对数线性 | 4.459 / 13.441 / 29.715 | .02993 / .07910 / .16147 |
| TinyDirectCNN | 2.828 / 7.049 / 11.027 | .07290 / .20872 / .34095 |
| 三帧 OLS | 5.952 / 15.548 / 31.488 | .03710 / .08773 / .16898 |
| 固定衰减 | 5.275 / 12.541 / 20.905 | .03267 / .07070 / .11517 |
| 地方时旋转 | **.4555 / .7426 / .9365** | **.00953 / .01492 / .01815** |

三帧 OLS 全部时效劣于两帧对数。相对 Persistence，OLS +1h 在索引 5–10 退化，+3/+6h 全部 29 层退化。固定衰减比 OLS 稳定，+1/+3h 改善全球绝对与 log RMSE，+6h 两者仍退化；+3h 在索引 2–10、+6h 在 0–14 与 27–28 退化。地方时旋转三时效均改善 29 层的绝对与 log RMSE，全部正值。+6h 低密度区域（2021 逐层目标 P5 阈值）的 log RMSE 从 .11519 降到 .01865，北极从 .06923 降到 .02475，南极从 .06596 降到 .03748。旋转法在该历史工程块中同时改善绝对和 log 指标，新方法均为 0 参数。旧块不能用于宣称独立排名。 [全域](../experiments/thermosphere_independent_event_production_v62/baseline_metrics.csv) · [逐层](../experiments/thermosphere_independent_event_production_v62/baseline_layer_metrics.csv) · [分区](../experiments/thermosphere_independent_event_production_v62/baseline_region_metrics.csv) · [误差图](../experiments/thermosphere_independent_event_production_v62/figures/forecast_errors.png)
