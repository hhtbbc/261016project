## 冻结方法与输入

沿用 Swarm A 的原全局历史估计。令 `b_H = median(log(ρ_obs) − log(ρ_model))`，`b_shrink = λ × b_H`，`ρ_corrected = ρ_model × numpy.exp(b_shrink)`。只增加固定的标量机制对照。Raw、ShrinkageHalf、Global 分别为 λ=0、0.5、1。0.5 是事前规定的中点；没有搜索、年份或纬区优化。保留原 Global 和 Latitude 实现。既有 LatitudeAdaptive18、Stale06 均仅供历史参考。

模型背景、UTC 和质量标识来自原冻结资料。参数加载先检查日期和左闭右开的历史窗，再核对文件 SHA、支持状态、至少 30 个有效历史样本、起止 UTC、历史样本内容 SHA 和 NumPy 乘数。对照 API 只接受同一个有序 ID 和 Raw 数组，验证共同 ID 哈希，再返回三个结果和方法代码 SHA。API 无观测结果参数，也不拟合下一轮使用的原系数。

06Z 只允许 [03:00,06:00)，18Z 只允许 [15:00,18:00)。V32 读取器先检查 UTC 索引再解码历史切片。终版 Swarm POD、GFZ 和物理背景只有事后可用性证据，标记 `HINDCAST_HISTORY_AVAILABLE` 和 `REALTIME_ASOF_UNVERIFIED`。真实发布时戳和背景帧的 as-of 身份需另行证实；日 Fobs 与含未来日的中心平均不作因果特征，06Z 不读同日 18Z。

## CPU 复核

25 项正反例全部通过。两组 06Z/18Z 合成 future poison 分别将截点起的密度乘 1e20，使用实际 V32 按记录切片读取器，参数及三个乘数逐值不变。另验证右端点拒绝、06Z 拒绝 18Z 历史、未见日期在读取前拒绝、非法 λ 或输入拒绝、参数 SHA 变化拒绝、共同 ID 失配拒绝，以及低纬等分区 N 不足时原联合结果保持 N/A。

独立复核检查了 16 个实际历史窗口的缓存和历史样本 SHA。对四日八窗以冻结 NumPy 对数原语和独立排序重算中位数，八个原始 b 均精确一致；用标量 exp 和乘法交叉核对 24 个候选参数及合成预测，沿用 `rtol=1e-13, atol=0`。λ=0 与 Raw、λ=1 与原 Global 在八个实际系数驱动的合成预测上逐元素精确一致。首次采用标量 log 的诊断在 2022-03-25 06Z 出现约 3.55×10⁻¹⁵ 的绝对差，近零系数的相对差约 1.88×10⁻¹³。最终沿用冻结实现的 NumPy 对数并独立计算次序统计量，保留标量 log 差异记录，容差和原参数均未改动。正式未来密度值未解码，正式评分为零。

## V36 公平比较与失败条件

先按发布清单核验参数、代码、背景与共同 ID，针对每个截止时点固定同一 `b_H`。只允许已准入的四日八窗。Raw 和原 Global 在全部 48 个未来子窗的旧共同 ID、样本数与 SHA 已核对，并以未来缓存的 UTC 元数据独立确认。2022 春季全日缓存的字节 SHA 首次在 V35 发布内绑定，历史窗口与 ID 仍独立对照 V18 原记录。未来阶段先输出背景与 ID 的共同对照，再由独立评估阶段连接未来实测。任何 ID 重复、缺失、错位、改动 SHA 或发现泄漏均停；查询不支持及区域 N<30 按原规则报告 N/A，不能算 PASS；禁止外推、fallback 或按误差筛样。

报告 1/3/6 小时累计窗和 0–1、1–3、3–6 小时非重叠块，保留低/中/高纬分组、四项联合判据及全部负面结果。四项为 RMSE 与 Relative RMS 严格降低、Relative P95 与低纬绝对 Relative Bias 不增加。开发诊断按整日分组，同日两个截点和重叠窗口不可跨组；本方法无跨日拟合。即使以后执行整日外留，结果仍属于已用数据上的开发诊断。真正未见检验须另行注册数据和流程。

本轮无需人工补数据。V36 需用户另行授权探索性比较，按收据写入新目录。没有启动 TIE-GCM、GPU、AI、DART 或轨道传播。源码和历史评分未改，V30–V33 发布清单与 V34、V20 等受保护证据已核对。保留 `SEED_POLICY=A_MAREQX_APPROVED`、`AUTUMN_ADAPTATION_UNVERIFIED`、`FOURTEEN_DAY_SPINUP_NOT_PROVEN_CONVERGED`、`EXTERNAL_DATUM_UNVERIFIED`、`FIXED_OFFSET_NOT_ADMITTED`、`Restart=FAIL`、`SCIENCE_TRAINING_READY=False`、`DART=NOT_ADMITTED`、`REAL_ORBIT=BLOCKED`。
