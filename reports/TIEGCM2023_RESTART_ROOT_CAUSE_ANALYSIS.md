# TIE-GCM 2023 Restart故障源码分析与最小动态验证设计

本任务为只读分析，新增模型积分0次、编译0次、源码补丁0份；没有执行B2、重跑24小时或启动spin-up。当前基线提交3c78935f724313591fcc3f48cb00b647f7ac3c90。证据清单和SHA256见experiments/tiegcm2023_restart_analysis_v1/static_audit.json；已有B1的逐变量数值见TIEGCM2023_CONTINUATION_VALIDATION.md。源码行号均指本地third_party/TIEGCM2.0/src，未来版本行号可能变化。

## 一、证据层级与结论

**代码确认事实**：primary序列化了18个当前状态、10个_NM、6个下边界，共34项；没有PHIM3D、EPHI3D、ELAM3D、EMZ3D、ED13D、ED23D字段。advance重新设istep=0，首步电场走与连续运行后续步不同的路径。实际B1计数、驱动和时间通过，28/34状态数值超差，6项下边界相同。

**证据支持的主假设**：地理POTEN回映射磁坐标势的损失，以及首步电场重建与pthreed保留场不等价，可能共同造成电动力差异，进一步传播到中性场。当前不能将这两个因素合并断言为唯一根因。

**尚未验证**：二者各自贡献、首次分歧位置、ESMF几何/季节缓存/其他初始化项影响、以及修复后是否全部满足冻结容差。只有终点B1数据不能证明因果链或唯一性。

## 三、首步与正常步的明确不等价代码

advance.F125重置istep；约358调用pefield，约559调用pdynamo，约577仅在需要历史时prepare_phig3d。pefield注释及2709明确istep>1使用上一时间步pthreed产生的电场，而istep1从phim3d梯度构造。pthreed先映射电场、再进行极点赋值，并在2507—2519设置emz3d上下边界；首步分支2699—2707只设置emz3d内层。后者在新进程中曾分配为0，所以在该路径返回前边界没有得到与pthreed同样的赋值。这个源级差别确实存在，是否通过后续边界外推/网格映射影响实际消费点，须跟踪ionvel，不能直接宣布它就是故障。

POTEN终点差9.4525V可以与电动力路径差异相容，但不代表证明了23:50回映射误差就是9.4525V。POTEN本身随新一轮dynamo解变化；还需对齐同一时刻同一执行阶段。

ionvel直接消费ex/ey/ez并做几何尺度变换，生成离子漂移；电动力通过离子—中性耦合、动量交换与加热等影响温度/风，继而改变组分、压力层几何高度与DEN。这是可检验的物理传递链，现有B1结果没有单独测定每一环节的贡献。

## 四、其他初始化路径与排除边界

- 已排除输入层面的复制损坏：23:50原件和副本SHA一致，append后的初始34字段保持原值。
- 已排除检查点缺少规定34字段/_NM、目标时刻错选、输出未来记录、明显漏/重复步：原生时间/iter112310→112320、10步，形状/dtype/单位/掩码通过。
- 已排除已审计时刻的GPI错误/固定覆盖：实际10个runtime读数及端点与独立插值相符。但这不证明未采样的所有内部驱动状态绝对相同。
- 六项下边界一致，降低了明显GSWM相位错误的可能性；gswm.F80—98仍在istep1重读缓存，不能推断所有中间潮汐/季节处理都已排除。
- pdynamo.F579/648/676有首步ESMF数据设置，几何/映射权重、apex与季节缓存仍需打点；源码存在SAVE数组并不自动说明它必须被restart序列化。
- 阈值没有改变。误差远超冻结数值容差，不归类为普通MPI舍入；但未做不同MPI规模模型实验来量化所有舍入放大。

第一层：复用原23:50primary副本，只做一条带只读观测的B1诊断（建议先1步60秒，若需要再另授权10步）。同一可执行物理配置，独立覆盖目录与run-tag，保持源文件不改。打点位置为：分配后；readsource/rdf4d恢复后且define_phim3d前；define_phim3d后；pefield前后；ionvel前后；pdynamo/pthreed前后；prepare_phig3d前后；时间层交换前后。前后记录同一year/day/mtime/iter/istep、itp/itc、网格索引、dtype、有效域/halo及边界。

记录变量：34主场、POTEN、phim3d、ephi3d/elam3d/emz3d、ed13d/ed23d、ex/ey/ez；加入2D势、几何/ESMF权重摘要和驱动。先做每rank内域/极区/上下边界分区min/max/L2及二进制校验，再只保存首步少量全数组（按实际磁网格维度预算）。单位沿真实声明和消费点确认，不将磁网格尺度化电场直接标作V/m。初始化前未定义或未分配内存不可读取，须显式记录allocated与定义状态。

第二层：旧参考没有原生磁势/电场快照，第一层只能证明恢复路径内的变换、不能证明相对原24小时连续状态的首次差异。无需重跑24小时，可从同一现有23:50检查点作为共同起点，另获授权运行带观测的连续20分钟参考与10+10分钟分段（3启动）。新连续首步同样经历旧恢复近似，因此只检验新共同轨迹在后一个10分钟边界的恢复，不能冒称复现旧24小时参考的隐藏状态。
