## 为什么这次方案合法

SOURCE_START=80 0 0选择原2002完整场，目标START首项77 0 0与其UTC小时/分钟相同，满足input.F948—960限制。START_YEAR2023、START_DAY77、CALENDAR_ADVANCE1，GPI开启、HEELIS，禁固定F107/F107A/KP/POWER/CTPOTEN及_TIME覆盖。没有把原文件日期改成2023。

原input.F支持相接的START/STOP/HIST序列；advance仅进行一次连续循环，没有在输出序列边界重启动力学。numfiles.F对相接序列不重复写接触点；output.F在满卷或新序列打开新文件。因此配置为：

| 输出序列 | START | STOP | HIST |
|---|---|---|---|
| 1 | 77 0 0 | 77 23 50 | 0 23 50 |
| 2 | 77 23 50 | 78 0 0 | 0 0 10 |
| 3 | 78 0 0 | 78 0 10 | 0 0 10 |

MXHIST_PRIM=1，提供四个不同OUTPUT文件名，得到00:00、23:50、次日00:00、00:10各一记录。次历史只保存77 23 50—78 0 10、每10分钟，含DEN/ZG等3个样本。稀疏完整主历史避免全日高频重复状态。

23:50文件本身即原生独立检查点，不需事后裁剪、修改time属性或拼接/构造_NM。该方式从生成之初消除“复制包含未来记录的长历史再追加”的风险。
